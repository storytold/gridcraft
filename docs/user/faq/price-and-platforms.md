GridCraft is free and open source. The README lists no subscription, no licence server and no telemetry. The code is dual-licensed under MIT or Apache-2.0, at your option.

## Where does it run?

- Windows 11, in x64 and arm64 builds. The release also has a 32-bit x86 build.
- macOS, as one universal app for Apple silicon and Intel Macs.
- Linux, on x86_64 and aarch64, as AppImage, Flatpak, `.deb`, `.rpm` or tarball. RISC-V builds exist too, as `.deb`, `.rpm` or tarball.
- FreeBSD, on x86_64.
- A web browser, with the static site from the release.

See [Install GridCraft](../getting-started/install.md) for the files.

## Is it ready to replace Microsoft Excel?

GridCraft is in alpha. The README says it covers 89% of the Excel ribbon commands in its catalog and 513 of Excel's 523 worksheet functions, and estimates it is about 50% ready for real work. Check that your workbooks open and calculate as you expect before you rely on it, and keep your originals.

GridCraft is an independent project and is not affiliated with Microsoft.
