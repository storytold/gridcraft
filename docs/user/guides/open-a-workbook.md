Click **File**, then **Open**, then **Browse…**, and choose your file. To start from nothing, click **File**, then **New**, then **Blank workbook**.

## Open a file

1. Click **File** at the left of the tabs row. The File view fills the window, with a list of pages on the left.
2. Click **Open**.
3. Click **Browse…**. Your system's file picker opens. Or click a workbook under **Recent**.
4. Choose the file and confirm.

To leave the File view without doing anything, click **Back** at the top of the list, or press Esc.

The picker's first filter, **Spreadsheets**, shows files ending in `.xlsx`, `.xlsm`, `.xls`, `.xlsb`, `.ods`, `.csv`, `.tsv`, `.txt` and `.json`. Other filters narrow it to Excel workbooks, Excel 97-2003 workbooks (`.xls`), binary workbooks (`.xlsb`), OpenDocument spreadsheets (`.ods`) or CSV.

On the **Data** tab, **Get Data (Text/CSV)** opens the same file picker.

If the workbook has a password, GridCraft asks for it. Some formats open with less than a full workbook: `.xls` files open without their formatting, and `.xlsb` and `.ods` files open with their values only. See [Which file formats can GridCraft open?](../faq/file-formats.md).

## Start a new workbook

1. Click **File**, then **New**.
2. Click **Blank workbook**, or one of the samples: **Household Budget**, **Quarterly Sales Dashboard** or **Gradebook**.

The **Home** page of the File view shows the same choices, with your recent workbooks under **Recent**.

The **Home** button at the left of the title bar opens a **Start a new workbook** window with the same choices.

## Close a workbook

Click **File**, then **Close**. If the workbook has unsaved changes, GridCraft asks "Do you want to save the changes you made to" the workbook, with **Don't Save**, **Cancel** and **Save**.
