Click **File**, then **Save**. A workbook that has no file yet goes to the **Save As** page, where **Browse…** opens the file picker so you can choose a name and folder.

## Save a workbook

1. Click **File**, then **Save**. The Save button in the title bar does the same.
2. If the workbook has never been saved, the **Save As** page opens. Click **Browse…** and type a name. If you leave off the extension, GridCraft adds `.xlsx`.

To save under another name, click **File**, then **Save As**, then **Browse…**.

The window title shows **Edited** after the file name while the workbook has unsaved changes.

## Turn on AutoSave

The **AutoSave** switch is at the left of the title bar. Its tooltip reads "AutoSave: save after every change (workbooks saved to a file)". The same setting is in **File**, then **Options**, as **Save .xlsx workbooks automatically after every change**. With it on, GridCraft saves a workbook shortly after you change it. It only does this for workbooks that already have an `.xlsx` file, so save a new workbook once first.

## Export a copy

1. Click **File**, then **Export**.
2. Choose one of:
   - **Create PDF** saves the sheet as a PDF that keeps its page layout.
   - **CSV (Comma delimited)** saves the active sheet as comma-separated text.
   - **Web Page (.html)** saves the workbook as a web page.
3. Choose a name and folder in the file picker.

These copies leave your workbook pointing at its own file. On the **Save As** page, **Save as type** offers the same formats.

The **Share** button at the right of the title bar has **Save a Copy as Excel Workbook (.xlsx)…**, **Export as CSV…** and **Export as Web Page (.html)…**. In the window that opens, type a path, or leave it empty and click **OK** to use the file picker. **Save a Copy as Excel Workbook (.xlsx)…** works like **Save As**, so the workbook then belongs to the new file.

## In a web browser

In the web version, saving opens the browser's save window where the browser has one, as Chrome and Edge do. Other browsers, such as Firefox and Safari, download the file instead.
