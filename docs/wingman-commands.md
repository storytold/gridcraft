# Wingman command and control index

Generated by `cargo xtask wingman-commands`. The desktop assistant uses the same index for command discovery.

**Direct** names a scoped native tool, not permission to supply arbitrary engine arguments. **Equivalent** achieves the worksheet result through another tool; it does not press the control. **Inspect** reads related workbook state. **Guide** leaves the action to the user. Desktop dialogs, OS clipboard, network, and host operations are not exposed merely by listing them. Dynamic choices such as workbook names, installed fonts and file picker entries depend on the active document or host.

A few controls share an engine command but have different routes:

- **Data Validation** sets a rule; **Clear Validation** removes one. Clearing a rule is never a substitute for creating it.
- **Text to Columns** can split a literal delimiter into a specified destination via `reshape_delimited`; the interactive fixed-width wizard remains manual.
- **Copy / Cut** can transfer between explicit worksheet ranges without using the system clipboard. **Paste** from another application is manual.
- **Format as Table** uses `create_table` and, if a gallery style was requested, `set_table_style`. Existing tables need only the latter. `apply_edits` can group them into one approval and Undo.
- **Draw pens** map to an explicit ink path, color and width rather than toggling the pointer. **Lasso Select** can inspect identified shapes; it does not select them for the user.
- **Edit Macro** can edit an open native macro draft; **Step Into**, execution, trust and imported VBA binaries remain outside that tool.
